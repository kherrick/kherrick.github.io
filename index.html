Block Garden - Knowledge Hub

10 Guides

Architecture deep-dives, controls, botany mechanics, modding scripts, and PDF world saves.

Explore all 10 Block Garden Knowledge Hub guides
  • Block Garden Knowledge Hub (/main/) Default hub landing page featuring an introduction to the 3D voxel sandbox engine, procedural terrain generation, farming mechanics, and custom element architecture.
  • Architecture & Procedural Engine (/main/about/) Deep architectural breakdown of the voxel game engine, covering the procedural world generator, custom rendering pipeline, and native Web Component encapsulation.
  • Controls, Modes & Save Ecosystem (/main/controls/) Complete player reference for desktop, mobile, and touch controls, game modes, camera perspectives, inventory interaction, and multi-format world saving.
  • Farming Mechanics & Botanical Species (/main/farming-and-botany/) Guide to soil preparation, hydration dynamics, seed germination, growth stages, crop harvesting, and botanical taxonomy.
  • Public Modding API & Script Gallery (/main/api-examples/) Extensible JavaScript modding API reference with copy-paste code recipes for custom block definitions, procedural structures, and runtime world manipulation.
  • Video Demos & Media Showcase (/main/demos-and-media/) Video demonstrations, gameplay capture, high-resolution screenshots, and animated media illustrating voxel landscapes and botanical growth.
  • PDF World Saves & Postcard Gallery (/main/world-saves-and-pdfs/) Exploration of the innovative PDF Save Game format, embedding serialized voxel worlds and playable seeds directly within printable PDF documents.
  • Web Platform Breakdown & Performance Engineering (/main/web-platform-and-performance/) Technical breakdown of browser optimization techniques, including zero-allocation rendering loops, Web Worker offloading, Service Worker caching, and WebGL memory tuning.
  • Agent Skills, Declarative Tools & Slash Commands (/main/agent-skills-and-tools/) Specification for AI agent integrations, declarative JSON tool definitions, workspace skills, and slash command pipelines interacting with the voxel world.
  • Block Garden Memory (/main/memory/) Agent routing directory and persistent memory specification detailing conventions for skills, tools, and game engine subsystem documentation.

Pwgen Knowledge Hub

10 Guides

Emscripten compilation pipeline, CLI flags, custom element integration, entropy analysis, and PWA optimization.

Explore all 10 Pwgen Knowledge Hub guides
  • pwgen Knowledge Hub (/main/) Hub landing page and interactive showcase for the classic Unix password generator compiled to WebAssembly for CLI, Custom Elements, ESM, Node.js, and web apps.
  • Architecture, Origins & WebAssembly Evolution (/main/about/) Historical and architectural examination of pwgen, from Theodore Ts'o's original C codebase to its modern WebAssembly compilation and Web Component packaging.
  • CLI Usage, Options & Node.js Integration (/main/cli-and-flags/) Complete command-line manual covering CLI flags, options, npx execution, global npm installation, and headless Node.js scripting patterns.
  • C to WebAssembly Compilation Pipeline (/main/wasm-and-compilation/) Deep technical dive into the Emscripten compilation toolchain, LLVM optimizations, memory sandboxing, and minimal binary size tuning for Wasm targets.
  • Native Custom Element (<x-pwgen>) & Framework Integration (/main/custom-element-and-web-integration/) Guide to embedding the <x-pwgen> declarative custom element into vanilla HTML, React, Vue, Angular, and other modern frontend frameworks.
  • Historical Evolution: Web Bundles (.wbn) & WAPM Distribution (/main/historical-targets-wbn-wapm/) Historical commit retrospective detailing experimental Web Bundles (.wbn), isolated web packaging, and WAPM registry distribution milestones.
  • Password Security, Phonetics & Deterministic SHA1 Seeding (/main/security-entropy-and-sha1/) Mathematical analysis of entropy bit calculations, pronounceable phonetic password algorithms, CSPRNG randomness, and deterministic SHA-1 seeding.
  • Web Platform Optimization & PWA Performance Engineering (/main/web-platform-and-performance/) Engineering overview of Web Platform performance, Service Worker caching strategies, streaming Wasm instantiation, and offline PWA capabilities.
  • Agent Skills, Declarative Tools & Slash Commands (/main/agent-skills-and-tools/) Documentation on declarative agent tools, headless skill pipelines, and slash commands enabling AI assistants to generate secure passwords deterministically.
  • Agent Memory Index (/main/memory/) Central directory for AI agents documenting memory conventions, available tools, skills, and password-generation subsystem references.
